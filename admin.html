AraméConfiguración inicial del panel

Esto se hace una sola vez. Le da permiso al panel para guardar cambios en la web. Después solo se entra con el PIN.

  1. Desde una computadora, con la sesión de GitHub abierta en la cuenta dueña de , tocá este link: crear el token del panel. Ya viene con el nombre y el permiso cargados.
  2. Si GitHub pide la contraseña o un código, ponelos.
  3. En Expiration elegí No expiration.
  4. Bajá hasta el final y tocá el botón verde Generate token.
  5. Copiá el código que empieza con ghp_ y pegalo acá abajo. GitHub lo muestra una sola vez.

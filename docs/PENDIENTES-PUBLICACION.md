# Pendientes para publicar la web de Aramé

Lista para repasar cuando se compre el dominio y se publique la web con la dirección final.

## 1. Dominio
- [ ] Comprar el dominio `.com.ar` en **nic.ar**, con la clave fiscal de ARCA del dueño (servicio "NIC Argentina" adherido en ARCA), para que quede a nombre del negocio.
- [ ] Crear la cuenta gratis de **Cloudflare** y apuntar el dominio ahí (cambiar los servidores DNS en nic.ar).
- [ ] Pasar la web a **Cloudflare Pages** conectada al repositorio (permite uso comercial; GitHub Pages no) y conectar el dominio, con https.
- [ ] Revisar que la tienda, el panel y los pedidos funcionen con la dirección nueva.

## 2. Google
- [ ] **Google Business Profile (ficha de Google Maps):** agregar el link de la web. Es lo que más visitas trae.
- [ ] **Google Search Console:** crear la propiedad con el dominio y verificarla con el código TXT en Cloudflare. Enviar el sitemap.
- [ ] **Estadísticas de visitas:** activar Cloudflare Web Analytics (un clic, sin cuenta de Google) o Google Analytics (pasar el código G-XXXXXXX para agregarlo a la web).
- [ ] Agregar a la web: sitemap.xml, robots.txt, descripción para buscadores, datos del local para Google (dirección, horario, tipo de comida) e imagen para cuando se comparte el link por WhatsApp.

## 3. Redes
- [ ] Poner el link de la web en la bio de Instagram (@aramecocina) y en el estado o perfil de empresa de WhatsApp.

## 4. Otros pendientes
- [ ] **Aviso por mail de pedidos:** activar FormSubmit desde el mail que llegó a aramecocina@gmail.com (botón "Activate Form") y confirmar con "Probar aviso por mail" en el panel. Si no aparece, usar Resend (ya armado en Supabase).
- [ ] Rechazar en el panel los pedidos de prueba (#8M25, #D639 y los que se hagan para probar).
- [ ] Cargar los productos nuevos del almacén (fotos que pasaron; faltan precios y descripción corta).
- [ ] Subir fotos de Instagram a la galería (Panel → Galería).
- [ ] Opcional: sumar aramecocina@gmail.com como administrador en GitHub y Supabase, o pasarles las cuentas.
